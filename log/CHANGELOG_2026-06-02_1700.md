## Bug 修复 — 摄像头串流 & 前端

### `/stream` MJPEG 超时
- **文件**: `robot_control/web_gui/server.py:161-177`
- **问题**: 摄像头设备被占用（RTMP 推流）时，`/stream` 端点无限挂起，浏览器 `<img>` 一直转圈
- **修复**: 增加 5 秒超时 + 每帧重置倒计时。无帧 5 秒后关闭流，浏览器触发 `error` 事件显示"摄像头未连接"

### Camera watchdog 逻辑
- **文件**: `robot_control/web_gui/server.py:185`
- **问题**: 条件为 `no_subs or no_activity`（OR），导致有人观看时也会被误切断
- **修复**: 改为 `no_subs and no_activity`（AND）

### WebRTC ontrack 时序
- **文件**: `robot_control/web_gui/static/app.js:74`
- **问题**: SRS API 连接成功即隐藏 MJPEG，但 RTMP 停掉后 `ontrack` 永不触发 → 黑屏
- **修复**: MJPEG 保持显示，只有真正收到视频轨道时才切换。8 秒无轨道回退 MJPEG

### 摄像头 CSS 布局
- **文件**: `robot_control/web_gui/static/style.css:284`
- **问题**: img/video 未绝对定位，导致画面偏移、被裁切
- **修复**: `position: absolute; top: 0; left: 0`，同时覆盖 `<video>` 元素
