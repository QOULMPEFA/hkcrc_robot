## Summary

Five-layer noise suppression pipeline for head→gimbal tracking:

```
Head IMU → EMA → Dead Zone ±3° → Deadband 0.3° → Rate Limit 300°/s → Quantize 0.5° → Servo
```

### v1.18 — Rate Limiter + Wide-Range Sliders
- Rate limit caps gimbal target velocity (default 300 °/s)
- All sliders widened: smoothing 0.02–1.0, deadband 0.02–2.0
- Number inputs alongside sliders for precise entry

### v1.19 — Hysteresis Dead Zone
- Gimbal freezes when head movement < dead zone threshold (default 3°)
- Only tracks intentional large head turns
- Ref: 1€ Filter (Casiez et al. 2012, ACM CHI)

### v1.20 — Target Angle Quantization
- Root cause: high-precision float targets cause servo encoder hunting
- Fix: `round(target / precision) * precision` (default 0.5°)
- Range 0.1–2.0°, adjustable via GUI
