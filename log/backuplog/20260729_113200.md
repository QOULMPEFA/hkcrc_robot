# v1.18 — Rate Limiter + Wide-Range Noise Suppression

**Date:** 2026-07-29 11:32
**Commit:** 9782f74
**Tag:** v1.18

## Changes

### Rate Limiter (关键新增)
- `head_rate_limit` — caps gimbal target velocity (°/s), default 60 °/s
- Kills rapid IMU fluctuations: real head motion is slow, noise is fast
- `math.isfinite()` guard so first-step after enable always reaches target

### Wider Ranges + Number Inputs
- Deadband: 0.02–2.0° (was 0.05–1.0), default 0.3°
- Smoothing (EMA): 0.02–1.0 (was 0.05–1.0), default 0.25
- Rate Limit: 5–500 °/s, default 60 °/s
- Each slider now has a paired `<input type="number">` for precise entry

### Three-Layer Noise Suppression Pipeline
```
Head IMU → EMA smoothing → Deadband gate → Rate limiter → Gimbal
```
1. **EMA (平滑)**: low-pass filter, removes high-frequency jitter
2. **Deadband (死区)**: ignores sub-threshold changes entirely
3. **Rate Limit (速率限制)**: caps max °/s, smooths remaining fluctuations

### Tuning Guide
- Still jittery: lower smoothing (0.05–0.15), raise deadband (0.5–1.0°), lower rate limit (10–30 °/s)
- Too sluggish: raise smoothing (0.5–0.7), lower deadband (0.1°), raise rate limit (100–200 °/s)
