# v1.16 — Head→Gimbal Gain Coefficient + Angle Limit Overrides

**Date:** 2026-07-29 11:15

**Tag:** v1.16

## Changes

### Configurable Gain Coefficient
- `head_yaw_gain` / `head_pitch_gain` — scale factor for head→gimbal angle ratio (default 1.0)
- Clamped range 0.1–5.0, adjustable via web GUI sliders
- Applied in `_head_to_gimbal()`: `(head - calib) * sign * gain`

### Angle Limit Overrides
- `gimbal_yaw_limits` / `gimbal_pitch_limits` config overrides (None = use gimbal module defaults)
- Priority chain: teleop config override → gimbal module config → hardcoded default
- `_effective_yaw_limits()` / `_effective_pitch_limits()` methods for runtime resolution
- STM32 reference: dual-axis PID uses yaw ±130°, pitch [-90, 40]; multi-mode uses yaw ±90°, pitch [-90, 60]

### Web GUI
- Gain sliders (0.1–3.0, step 0.05) with live value display and "Apply Gains" button
- Limit display row showing effective Yaw/Pitch bounds
- SocketIO handlers: `teleop_set_head_gains`, `teleop_set_gimbal_limits`
- i18n keys for gain/limit labels (zh + en)

### Config
```python
"teleop": {
    "host": "192.168.56.101",
    "head_yaw_sign": -1,
    "head_yaw_gain": 1.0,
    "head_pitch_gain": 1.0,
}
```
