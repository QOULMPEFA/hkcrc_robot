# Backup Log — v1.24 (2026-08-07 20:45)

## 变更摘要

### D455 Quest 图传热切换（本轮核心）
- `realsense_quest_bridge.py`：UDP 推流改外层循环，定期检查 `/tmp/realsense_bridge.source` 的 mtime，源变化自动重连 MJPEG 源（TCP 控制连接与 UDP 目标地址不变，头显端零改动）
- 源文件作为唯一真相，桥接进程存活期长于 Flask，`restart` 不再可能用错摄像头
- 源不存在时服务端返回 404，桥接记日志并退出，不空转重试
- `start_realsense_quest.sh`：新增 `source <id>` 动作（只写源文件，不重启进程），`restart` 沿用文件内值
- `teleop.py`：`_resolve_video_source()` 按 id → 序列号 → 型号名三级解析，`_video_action_lock` 串行化 start/stop/restart，状态广播增加 `video_source` 字段
- 图传默认源从 cam0 改为 D455（`server.py` 配置 `default_camera: "D455"`）

### Orbbec 深度/双目相机（与 D455 合并）
- `camera.py`：OrbbecSource 类（color/depth/stereo 三模式），`camera_set_mode` socket handler，`camera_mode_result` 事件
- Web GUI 摄像头面板新增模式切换行 + 图传按钮（仅 teleop 模块加载时渲染）
- `app.js` / `i18n.js`：Orbbec 模式切换 UI + 中英文翻译
