# Backup Log — v1.23 (2026-07-31 17:35)

## 变更摘要

### 摄像头自动检测系统
- 启动时自动扫描 `/dev/video*` 发现所有物理摄像头（不再硬编码设备路径）
- 幽灵节点过滤：检查 `/sys/class/video4linux/*/device` 是否存在，跳过已断开 USB 设备的残留节点
- USB 设备级去重（`_deduplicate_by_usb_device`）：通过 sysfs 树将多个 `/dev/video*` 节点归组到同一物理 USB 设备
- RGB/Depth 节点甄别（`_pick_color_node`）：使用 `v4l2-ctl --list-formats` 检查像素格式，优先选择 YUYV/MJPG/RGB 颜色源，过滤 Y16/Z16 深度节点
- Metadata 节点过滤：`v4l2-ctl --info` 检查 Device Caps bit 0（Video Capture），排除 Metadata Capture 节点
- Web GUI 新增"扫描摄像头"按钮，支持热插拔检测（无需重启服务）
- 中英文 i18n 翻译（扫描摄像头 / Scan Cameras）
- 线程安全：`threading.Lock()` 保护 `_sources` 字典的并发访问
- 配置简化：`"auto_detect": true` 替代硬编码的 `"devices"` 列表

### 云台电机自动重连
- CH340 串口舵机控制器掉电后自动恢复连接
- `_poll_loop()` 中每 ~5 秒重试连接，成功后同步当前角度
- 适用场景：云台电机在服务启动后上电

### 涉及文件
- `robot_control/camera.py` — 自动检测、去重、深度过滤、热插拔扫描
- `robot_control/gimbal.py` — 掉电自动重连
- `robot_control/web_gui/server.py` — auto_detect 配置 + camera_scan 事件注册
- `robot_control/web_gui/static/app.js` — 扫描按钮 + 点击处理
- `robot_control/web_gui/static/i18n.js` — 中英文翻译
