# Session Log — 2026-06-03 10:01

## Jetson 重启后 UGV 断连修复

- 问题：Jetson 重启后 UGV 底盘显示"未连接"、电池 0.0V
- 根因：`ugv_bridge` 没有 systemd 服务，重启后未自动启动
- 修复：创建 `ugv_bridge.service`（依赖 `setup-can0.service`），设 enable

## UGV 运行日志窗口

- 参照升降平台模式，`ugv.py` 新增 `UGVLogEntry` + 80 条环形缓冲
- `index.html` + `app.js` 新增 UGV 诊断行（车辆状态/控制模式/SOC 颜色编码）
- 新增"使能 CAN 模式"和"清除故障"按钮
- 自动记录：Bridge 连接/断开、速度指令、车辆状态变化、控制模式切换

## UGV 运动控制修复

- `ugv_bridge.cpp`：启动时增加 `ResetRobotState()` 调用，新增 `reset` 命令
- `enable` 命令现在先清除故障再使能
- `ugv.py`：新增 `reset()` / `enable()` SocketIO 事件

## 死锁修复

- 问题：部署后 Web GUI 所有数据消失（UGV + 升降平台）
- 根因：`_handle_message` 持有 `Lock` 时调用 `_add_log` 再次获取同一锁，自身死锁
- 修复：`threading.Lock()` → `threading.RLock()`
