# v1.9 — Camera USB Reset Recovery + Keyboard Bindings + Shutdown Fix

**Date:** 2026-06-12 04:45

## Changes

### Camera Module (`robot_control/camera.py`)
- **Fix** Non-blocking frame loop: replaced `proc.stdout.read(4096)` with `select.select()` + `os.read()` — signal-loss detection now fires within 5s instead of blocking forever
- **New** USB device reset recovery (`_reset_usb()`): unbinds/rebinds USB device via sysfs to recover from UVC firmware errors (EPIPE on GET_DEF control queries)
- **New** ffmpeg stderr capture: stderr drained to a thread and logged on kill for diagnostics
- **Fix** Device detection: checks Device Caps (not just Capabilities) to filter metadata-only `/dev/video2` from UVC cameras
- **New** `camera_reset` SocketIO handler for manual GUI-triggered reset
- **Fix** `fuser -k` on device before launching ffmpeg to clean orphaned processes
- **Fix** Auto-reset: `_cycle_device()` triggers USB reset on single-device setups instead of doing nothing

### Server (`robot_control/web_gui/server.py`)
- **Fix** Shutdown/reboot: `subprocess.Popen` now uses `echo orangepi | sudo -S systemctl poweroff/reboot` (root required via polkit)

### Web GUI
- **New** `KeyBindingManager` — keyboard-to-action mapping with localStorage persistence, hold/click types, conflict resolution, listening mode for rebinding
- **New** Camera reset button with loading state and signal status display
- **Fix** Mobile header: compact at 640px breakpoint (hides h1/layout-controls/role-badge), reboot/shutdown hidden only at 400px
- **Fix** Power modal button centering (`.btn-row.center` CSS)
- **New** i18n keys: camera reset/status, keyboard bindings settings (zh + en)

### Systemd Service (`/etc/systemd/system/robot_control_panel.service`)
- **New** `ExecStartPre=/bin/bash -c "fuser -k /dev/video* 2>/dev/null; sleep 0.5; true"` — cleans stale ffmpeg before start
- **New** `TimeoutStopSec=15` — faster service restart

## Root Cause: Camera No-Signal
The UVC camera (Alcor Micro PC Camera 058f:1412) had a firmware bug causing `Failed to query (GET_DEF) UVC control 13 on unit 1: -32 (EPIPE)`. This left the device in a wedged state where it opened successfully but produced zero frames. USB unbind/bind resets the device state.
