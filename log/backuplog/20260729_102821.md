# v1.15 — XR Teleop SDK Restructure + Head→Gimbal Tracking

**Date:** 2026-07-29 10:28
**Commit:** 2a09358

## Changes

### Teleop SDK Restructure
- `robot_control/teleop.py` → `teleoperation_sdk/teleop.py` (portable across projects)
- `robot_control/ur5_ik.py` → `teleoperation_sdk/ur5_ik.py`
- New `teleoperation_sdk/__init__.py` — package init, public API exports
- New `teleoperation_sdk/setup_xr_teleop.sh` — Jetson build script
- `robot_control/robot.py` — registry updated to new path

### Quest 3 Head Tracking → Gimbal
- Forward-vector quaternion→yaw/pitch conversion (fixes axis swapping in OpenXR)
- EMA exponential smoothing filter (alpha=0.35, configurable via `head_smoothing`)
- 20Hz update rate with 0.15° deadband for smooth continuous motion
- Independent arm/head toggle switches (separate enable/disable per subsystem)

### Gimbal Module
- New `robot_control/gimbal.py` — 2-axis Fashion Star UART servo gimbal
- Linear calibration (two-point), damping mode, home position

### Web GUI
- Teleop panel: gimbal head tracking section (status, angles, 4 control buttons)
- i18n keys for head tracking labels (zh + en)

### Config
```python
"teleop": {
    "host": "192.168.56.101",
    "head_yaw_sign": -1,       # flip yaw direction for servo mounting
    "head_smoothing": 0.35,    # EMA alpha (0.1=smooth, 1.0=raw)
}
```
