# v1.17 — Configurable Deadband + EMA Smoothing for Gimbal Jitter Suppression

**Date:** 2026-07-29 11:25
**Commit:** ed1f916
**Tag:** v1.17

## Changes

### Jitter Suppression
- Deadband increased from 0.15° → 0.3° default (cuts IMU noise)
- Deadband + EMA smoothing now adjustable via web GUI sliders (no restart needed)
- `teleop_set_head_config` SocketIO handler — applies deadband + smoothing in real-time

### GUI Sliders
- **死区 (Deadband)**: 0.05–1.0°, step 0.05 — ignore angle changes below threshold
- **平滑 (Smoothing)**: 0.05–1.0, step 0.05 — EMA filter strength (lower = heavier filtering)
- "应用" button sends both + gain values at once

### Tuning Guide
- Servo jitter → raise deadband (0.4-0.6°) or lower smoothing (0.1-0.2)
- Too sluggish → lower deadband (0.1-0.2°) or raise smoothing (0.5-0.7)

### Config
```python
"teleop": {
    "head_deadband": 0.3,
    "head_smoothing": 0.35,
}
```
