## error_code=512 根因分析

- `SYSTEM_ERROR_HL_COMM_MASK` (bit 9, 0x0200)：底层控制器检测到高层 CAN 通信丢失
- 触发原因：Jetson 重启后 ugv_bridge 未自动启动（当时无 systemd 服务），CAN 总线上无指令
- `ResetRobotState()` + `EnableCommandedMode()` 软件复位无法清除此故障
- **实际原因是底盘需要调零**，调零后错误即可清除

## RC 信号数据损坏

- `rc_swb = -173755904`（应为 0/1/2 三档开关值），`rc_swa = 65535 (0xFFFF)` — 数据异常
- 可能原因：RC 遥控器电量不足、接收机需重新对频、接收机连线松动
- SWB 是控制命令来源的关键开关（UP=CAN模式），数据损坏导致机器人无法切换控制模式

## 底盘零点调零校准步骤

使用 RC 遥控器进行调零：

| 开关 | 档位 | 说明 |
|------|------|------|
| SWA | DOWN | 进入校准模式 |
| SWB | UP | CAN 命令模式 |
| SWD | DOWN | - |
| SWC | DOWN / MID / UP | 灵敏度：粗调 / 中调 / 微调 |

- **左摇杆 4 个方向** → 选择对应位置的转向电机（例：左上=左前轮，右上=右前轮）
- **右摇杆 左右** → 调整角度
- **左滚轮** → 两个方向累加调节位置
- **KEY1** → 将当前位置设为零点
- **KEY1（任意情况）** → **强制清除所有错误**（仅在确保安全时使用）
- **POWER** → 长按开机
