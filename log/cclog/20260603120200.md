# Session Log — 2026-06-03 12:02

## 方向键左转/右转修复

- 问题：d-pad 左转/右转无效，前进后退正常
- 根因：`ugv_bridge.cpp` 中 `SetMotionCommand(linear, angular)` 在 kDualAckerman 模式下将 angular 当作转向角，linear=0 时车轮不驱动
- 修复：零速转向时自动切换 kSpinning 差速自旋模式，angular 作为旋转速度传给 angular_vel 参数
  - `linear≈0 & angular≠0` → `SetMotionMode(kSpinning)` + `SetMotionCommand(0, 0, angular)`
  - 其他 → `SetMotionMode(kDualAckerman)` + `SetMotionCommand(linear, angular)`

## 升降平台 CAN 故障

- 问题：SDO timeout，无法读写驱动器参数
- 根因：can0 进入 BUS-OFF 状态（berr-counter tx 248），CAN 总线物理断开
- 原因：底盘断电时 Jetson 持续尝试发送 CAN 帧，累积错误后控制器自动离线
- 修复：`ip link set can0 down && ip link set can0 up type can bitrate 500000` 重启 CAN 接口

## WebRTC 摄像头降级 MJPEG 原因

- 问题：刷新后显示"WebRTC 协商中"→ 8s →"MJPEG"
- 根因：NATFRP 只转发 TCP，WebRTC 媒体需要 UDP，视频流永远无法到达浏览器
- 另外：SRS 无推流端（camera_server.service 已 dead），即使 UDP 通也没有视频源
- 结论：MJPEG over TCP 是当前方案下的正确选择，WebRTC 回退逻辑是预期行为
