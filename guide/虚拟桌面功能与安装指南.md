# 虚拟桌面：无显示器远程桌面（功能 + 安装指南）

适用机器：**Jetson Thor**（`192.168.20.66`，Ubuntu 24.04）· 也适用于旧 Jetson / 同类 Tegra 设备。
最后更新：2026-08-27。部署细节见 [ssh_to_jetson_thor.md](ssh_to_jetson_thor.md)。

---

## 1. 功能简介

虚拟桌面让机器人主机**在没有任何物理显示器/HDMI 连接的情况下**，也能启动完整的 GNOME 桌面，配合 **AnyDesk** 即可从电脑远程操作，完全无头（headless）运行。

典型场景：
- 机器人部署在现场，不方便插显示器
- 通过 AnyDesk（或其它远程工具）远程控制桌面、看 GUI、调参数
- 重启后无需人跑到机器旁边，桌面自动就绪

**一条命令切换**：`to-headless`（虚拟桌面）/ `to-screen`（物理显示器），改完自动重启生效。

---

## 2. 工作原理

虚拟桌面由 **三层** 叠加实现：

| 层 | 作用 | 关键配置 |
|---|---|---|
| ① GDM 显示管理器 | 开机启动 X 图形界面 | `display-manager → gdm3.service`（enabled）+ `graphical.target` |
| ② NVIDIA 空显支持 | 允许 X 在没有显示器时启动 | `/etc/X11/xorg.conf` 里 `Option "AllowEmptyInitialConfiguration" "true"` |
| ③ dummy 虚拟显卡 | 提供 1920x1080 虚拟 framebuffer | `/usr/share/X11/xorg.conf.d/xorg.conf`（Driver "dummy"） |

配合设置：
- `WaylandEnable=false` → 强制走 X11（GDM 才能用虚拟 framebuffer）
- `gdm.service.d/override.conf` 里 `ExecStartPre=` → 清掉 NVIDIA 默认的 GDM 前置步骤（否则无头启动会卡住）
- 自动登录 → 重启后无需输密码直接进桌面，AnyDesk 一连就是桌面

**切换命令原理**：`to-screen` 把 dummy 配置文件挪成 `.bak`（X 只走真显卡，需插显示器）；`to-headless` 恢复该文件（X 用 dummy 虚拟屏，无显示器也能跑）。两者都会 `reboot`。

## 3. 安装指导

### 3.1 安装 dummy 虚拟显卡驱动

```bash
sudo apt-get update
sudo apt-get install -y xserver-xorg-video-dummy
```

### 3.2 创建 dummy 虚拟屏配置

文件：`/usr/share/X11/xorg.conf.d/xorg.conf`（root 所有，权限 644）：

```bash
sudo tee /usr/share/X11/xorg.conf.d/xorg.conf > /dev/null <<'EOF'
Section "Device"
    Identifier  "Configured Video Device"
    Driver      "dummy"
    VideoRam    256000
EndSection

Section "Monitor"
    Identifier  "Configured Monitor"
    HorizSync   31.5-48.5
    VertRefresh 50-70
EndSection

Section "Screen"
    Identifier  "Default Screen"
    Monitor     "Configured Monitor"
    Device      "Configured Video Device"
    DefaultDepth 24
    SubSection "Display"
        Depth 24
        Modes "1920x1080"
    EndSubSection
EndSection
EOF
sudo chown root:root /usr/share/X11/xorg.conf.d/xorg.conf
sudo chmod 644 /usr/share/X11/xorg.conf.d/xorg.conf
```

### 3.3 确认 NVIDIA 空显支持（Tegra 一般已带）

`/etc/X11/xorg.conf` 的 Device 段里应有：

```
Option "AllowEmptyInitialConfiguration" "true"
```

若无则补上（`/etc/X11/xorg.conf` 不存在时新建，Tegra 设备还需 `xorg.conf.d/tegra-drm-outputclass.conf` 加载 nvidia 驱动）。

### 3.4 确认 GDM 走 X11

`/etc/gdm3/custom.conf` 的 `[daemon]` 段：

```
WaylandEnable=false
```

若机器启过 gdm 无头启动失败，加 gdm override：

```bash
sudo mkdir -p /etc/systemd/system/gdm.service.d
sudo tee /etc/systemd/system/gdm.service.d/override.conf > /dev/null <<'EOF'
[Service]
ExecStartPre=
EOF
```

### 3.5 添加切换命令到 `~/.bashrc`

```bash
cat >> ~/.bashrc <<'EOF'

# ── 虚拟桌面开关 ──
alias to-screen='sudo mv /usr/share/X11/xorg.conf.d/xorg.conf /usr/share/X11/xorg.conf.d/xorg.conf.bak && sudo reboot'
alias to-headless='sudo mv /usr/share/X11/xorg.conf.d/xorg.conf.bak /usr/share/X11/xorg.conf.d/xorg.conf && sudo reboot'
EOF
source ~/.bashrc
```

### 3.6 （推荐）开启自动登录

重启直接进桌面，AnyDesk 免登录直达。编辑 `/etc/gdm3/custom.conf` 的 `[daemon]` 段：

```
AutomaticLoginEnable=true
AutomaticLogin=<你的用户名>     # Thor 上是 hkcrc1
```

### 3.7 （推荐）安装并配置 AnyDesk

```bash
# 下载 arm64 deb（aarch64）后安装
sudo dpkg -i anydesk_*.deb          # 或 sudo apt install ./anydesk_*.deb
sudo systemctl enable anydesk       # 开机自启
sudo systemctl start anydesk
anydesk --get-id                    # 记下远程连接 ID
echo '你的密码' | sudo anydesk --set-password   # 设置无人值守密码
```

### 3.8 重启生效

```bash
sudo reboot
```

重启后验证：`who` 应显示 `<用户名> :1`；`DISPLAY=:1 xrandr` 应输出 1920x1080 虚拟屏；`systemctl status gdm3 anydesk` 均 active。

## 4. 使用

### 4.1 切换虚拟桌面 / 物理屏

| 命令 | 效果 |
|---|---|
| `to-headless` | 无显示器虚拟桌面（1920x1080），远程用 |
| `to-screen` | 物理显示器模式（需接屏） |

两者都会自动重启。运行时会提示输入 **sudo 密码**（Thor 上是**单个空格**）。

> 别名要新终端或 `source ~/.bashrc` 才生效。

### 4.2 AnyDesk 远程连接

1. 电脑开 AnyDesk，输入机器的 **ID**（Thor 为 `1285628773`）
2. 输入无人值守密码
3. 进入桌面后即可操作

### 4.3 开启 / 关闭开关速查

| 功能 | 开 | 关 |
|---|---|---|
| AnyDesk 自启 | `sudo systemctl enable anydesk` | `sudo systemctl disable anydesk` |
| 自动登录 | custom.conf 加 `AutomaticLoginEnable=true` | 注释掉这两行 |
| 虚拟桌面（图形启动） | `sudo systemctl set-default graphical.target` | `sudo systemctl set-default multi-user.target`（纯命令行） |
| 虚拟桌面（dummy 屏） | `to-headless` | `to-screen` |

改配置后 `sudo reboot` 生效（`gdm3` 相关可 `sudo systemctl restart gdm3`，会短暂断开桌面）。

## 5. 故障排查

**重启后没有桌面 / 黑屏**
```bash
cat /var/log/Xorg.0.log | grep -iE '(EE)|dummy|nvidia'   # 看 X 报错
systemctl status gdm3 --no-pager
```
大概率：`xserver-xorg-video-dummy` 没装，或 `/usr/share/X11/xorg.conf.d/xorg.conf` 被 `to-screen` 移走了（跑一次 `to-headless` 恢复）。

**AnyDesk 连不上**
```bash
systemctl status anydesk;  anydesk --get-id
echo '新密码' | sudo anydesk --set-password   # 重置无人值守密码
```

**自动登录没生效**
检查 `/etc/gdm3/custom.conf` 里用户名是否正确、`[daemon]` 段是否有重复的 `AutomaticLoginEnable`。

**sudo 密码是空格、按重启没反应**
确认 Web GUI 系统设置里 "Sudo 密码" 已设为空格，且 `server.py` / `camera.py` 的默认 sudo 密码已是 `" "`（2026-08-27 已修，重启/关机走 stdin 管道传密码，不再 strip）。见 `ssh_to_jetson_thor.md`。

## 6. 相关文件清单

| 文件 | 作用 |
|---|---|
| `/etc/X11/xorg.conf` | nvidia 驱动 + `AllowEmptyInitialConfiguration` |
| `/usr/share/X11/xorg.conf.d/xorg.conf` | dummy 虚拟显卡（1920x1080）—— `to-screen`/`to-headless` 开关的对象 |
| `/etc/X11/xorg.conf.d/tegra-drm-outputclass.conf` | Tegra 加载 nvidia OutputClass |
| `/etc/gdm3/custom.conf` | `WaylandEnable=false` + 自动登录 |
| `/etc/systemd/system/gdm.service.d/override.conf` | 清空 NVIDIA gdm `ExecStartPre=` |
| `~/.bashrc` | `to-screen` / `to-headless` 别名 |
| `/lib/systemd/system/gdm3.service` | 显示管理器（`display-manager` 别名） |

包：`xserver-xorg-video-dummy`、`anydesk`（arm64）。
