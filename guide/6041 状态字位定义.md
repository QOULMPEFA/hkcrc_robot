### 6041 状态字位定义

| 位 (Bit) | 功能 |
| :--- | :--- |
| **0** | 已准备好 |
| **1** | 等待使能 |
| **2** | 已使能运行 |
| **3** | 发生故障 |
| **4** | 已上电 |
| **5** | 快速停止激活 |
| **6** | 不可运行 |
| **7-8** | NA |
| **9** | 远程控制 |
| **10** | 目标到达 |
| **11** | NA |
| **12-13** | 运行模式相关 |
| **14** | NA |
| **15** | 原点已找到 |

**其他位的补充说明：**
*   **位 4 (已上电)**：当驱动器投入电源后，该位将被置位（置 1）。

**状态字使用须知：**
*   ◆ 状态字的每一个 bit 位单独读取无意义，必须与其他位共同组成，以反馈伺服当前状态。
*   ◆ bit0 ~ bit9 在各伺服模式下意义相同，在控制字 6040h 按顺序发送命令后，伺服会反馈一确定的状态。
*   ◆ bit12 ~ bit13 与各伺服模式相关（请查看不同模式下的控制指令）。
*   ◆ bit10、bit15 在各伺服模式下意义相同，用于反馈伺服执行某伺服模式后的状态。
