### 2.1 对象字典 (Object Dictionary)

**对象字典概述：**
对象字典是设备规范中最重要的部分。它是一组参数和变量的有序集合，包含了设备描述及设备网络状态的所有参数。通过网络，主站可以采用有序的预定义方式来访问这组对象。
CANopen 协议采用了带有 **16 位索引 (Index)** 和 **8 位子索引 (Sub-index)** 的对象字典结构。

**对象字典区域划分：**

| 索引范围 (16进制) | 区域定义及功能说明 |
| :--- | :--- |
| **0000h - 0FFFh** | **数据类型区**：用户无访问意义。 |
| **1000h - 1FFFh** | **通讯配置区**：按照 CiA301 协议定义通信对象参数以及设备类型等。 |
| **2000h - 5FFFh** | **制造商特定区**：制造商自定义对象区。**AIMOTOR 驱动器将该区域定义为所有参数功能码对象。** |
| **6000h - 9FFFh** | **标准化设备配置区**：按照 CiA402 协议定义的一些常用 CiA402 运动控制对象（如控制字、状态字、目标位置等）。 |

---

### AIMOTOR 驱动器参数映射规则

在 2000h - 5FFFh 的制造商特定区，AIMOTOR 驱动器的面板参数（功能码）与 CANopen 对象字典地址之间存在固定的换算关系。

**映射公式：**
*   **对象字典索引 (Index)** = `0x2000` + `功能码组号`
*   **对象字典子索引 (Sub-index)** = `功能码组内偏置的十六进制` + `1`

*(注：计算子索引时，需要先将十进制的组内偏置加 1，然后再转换为十六进制。)*

**映射关系举例说明：**

| 参数功能码名 | 功能码组号 (16进制) | 组内偏置 (10进制) | ➡️ | 对象字典索引 (16进制) | 对象字典子索引 (16进制) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **H02-00** | `0x02` | `00` | | **`0x2002`** | **`0x01`** *(0+1=1)* |
| **H03-09** | `0x03` | `09` | | **`0x2003`** | **`0x0A`** *(9+1=10)* |
| **H0B-26** | `0x0B` | `26` | | **`0x200B`** | **`0x1B`** *(26+1=27)* |
| **H12-20** | `0x12` | `20` | | **`0x2012`** | **`0x15`** *(20+1=21)* |

**计算示例解析 (以 H0B-26 为例)：**
1.  **组号**为 `0B`，因此索引为 `0x2000 + 0x0B = 0x200B`。
2.  **组内偏置**为 `26`（十进制），加 `1` 后等于 `27`（十进制）。将十进制的 `27` 转换为十六进制即为 `1B`，因此子索引为 `0x1B`。
