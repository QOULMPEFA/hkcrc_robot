# 用Jetson AGX通过CAN通讯控制步进电机

## 硬件接线

| **SN65HVD230 模块引脚** | **Jetson AGX 引脚 (40-pin)** | **引脚编号** | **说明** |
| --- | --- | --- | --- |
| **3.3V (VCC)** | 3.3V Power | **Pin 1** | 供电 |
| **GND** | Ground | **Pin 6** | 公共地线 |
| **CRX (RX)** | CAN0_TX | **Pin 29** | 发送信号 |
| **CTX (TX)** | CAN0_RX | **Pin 31** | 接收信号 |

### 第一步：开启引脚功能

在终端运行 Jetson 官方配置工具：

Bash

`sudo /opt/nvidia/jetson-io/jetson-io.py`

1. 选择 **Configure Jetson 40pin Header**。
2. 选择 **Configure header pins manually**。
3. 找到并勾选 **can0** (对应的引脚是 29, 31)。
4. 选择 **Back** -> **Save pin changes** -> **Save and reboot to reconfigure pins**。
5. **重启 Jetson。**

---

### 第二步：激活 CAN 接口

重启后，执行以下指令：

Bash

`# 设置波特率并开启（与电机一致，如 500k）
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 500000
sudo ip link set can0 up`

---

## 第三步：验证与测试

### 1. 测试接收

接好线并上电，输入：

Bash

`candump can0`

如果你看到滚动的十六进制数据（例如 ID `211` 或 `221`），说明接线和配置完全正确。

### 控制命令

根据您的要求，我将所有指令整合成了标准的 `cansend` 终端格式。

这里依然假设您的设备 **Node ID 为 1**（即 SDO 接收 ID 为 `601`）。如果您的设备 ID 不同，请将 `601` 替换为 `600 + ID` 的十六进制值。

---

### 🚀 完整控制指令集 (can0)

### 第一阶段：启动与使能

在执行运动之前，必须按照 CANopen 状态机顺序发送以下指令：

| **功能** | **终端指令** | **说明** |
| --- | --- | --- |
| **1. 准备就绪** | `cansend can0 601#2B40600006000000` | 写入 Controlword 0x06 |
| **2. 开启主回路** | `cansend can0 601#2B40600007000000` | 写入 Controlword 0x07 |
| **3. 使能运行** | `cansend can0 601#2B4060000F000000` | 写入 Controlword 0x0F (电机进入使能状态) |

---

### 第二阶段：模式切换与速度执行

使能后，设置运行模式并给定速度：

| **功能** | **终端指令** | **说明** |
| --- | --- | --- |
| **设置速度模式** | `cansend can0 601#2F60600003000000` | 写入模式 3 (Profile Velocity) |
| **设置目标速度** | `cansend can0 601#23FF600010270000` | 设定速度为 10000 Pul/s (`0x2710`) |

---

### 第三阶段：停止与释放

停止动作或紧急情况下释放电机力矩：

| **功能** | **终端指令** | **说明** |
| --- | --- | --- |
| **停止运行** | `cansend can0 601#23FF600000000000` | 将目标速度设为 0 |
| **释放力矩** | `cansend can0 601#2B40600006000000` | 切换回准备就绪状态，电机失去轴向力 |
